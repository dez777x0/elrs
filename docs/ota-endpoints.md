# OTA: типичные хосты и пути (ExpressLRS / ELRS Web Flasher)

В приложении путь OTA задаётся вручную; ниже — ориентиры для поля **хост** и **путь загрузки**. Точный URL зависит от **версии прошивки RX** и режима Wi‑Fi; при сомнении смотрите документацию вашей сборки ELRS или экран веб-интерфейса приёмника.

## Частые комбинации

| Сценарий | Базовый URL (пример) | Путь / действие | Комментарий |
|----------|----------------------|-----------------|-------------|
| RX в режиме точки доступа (классика) | `http://10.0.0.1` | `update`, `upload`, `api/update` | В UI flasher есть кнопки-пресеты; один из вариантов часто совпадает с вашей сборкой. |
| Другая подсеть / mDNS | `http://elrs_rx.local` или IP из роутера | как у устройства | Зависит от того, как RX объявлен в сети. |
| HTTPS на RX | `https://…` | по документации сборки | Реже; сертификат может быть самоподписанным — браузер попросит исключение. |

## Рекомендации по отладке

1. Откройте в браузере тот же базовый URL, что в поле OTA — убедитесь, что открывается веб-интерфейс RX.  
2. Если POST из flasher возвращает **404**, смените **путь** (пресеты в UI).  
3. **CORS**: если фронт на другом origin, RX может не отдавать заголовки для cross-origin POST — тогда используйте тот же хост или прокси на своём сервере (это уже вне scope чистого статического flasher).
