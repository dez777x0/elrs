# Матрица транспортов и платформ

| Платформа / браузер | Web Serial (прямой UART) | WebUSB (эксп.) | OTA HTTP | Native Bridge |
|---------------------|--------------------------|----------------|----------|---------------|
| Windows 10/11, Chromium (Chrome, Edge) | Да, основной путь | Опционально (VID Espressif), ограничено устройством | Да | Если оболочка инжектит мост |
| macOS, Chromium | Да | Опционально | Да | Если мост |
| Linux, Chromium | Да (права udev) | Опционально | Да | Если мост |
| Android Chrome | Если API Serial доступен (редко/зависит от сборки) | Зависит от устройства | Да | Рекомендуется для стабильного UART |
| iOS Safari | **Нет** (нет Web Serial/USB для произвольного UART) | **Нет** | **Да** (локальный файл → Wi‑Fi точка доступа RX) | Для будущего UART через оболочку |

Приложение **не заявляет** проводную USB‑прошивку на iOS в обычном браузере. Бейдж в UI отражает фактические `navigator.serial` / `navigator.usb` и пользовательский выбор режима (OTA / passthrough / direct).
